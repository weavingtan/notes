:::summary[设计初心]
一个好的个人网站，是工程师和创作者在数字世界的精神家园。
它不应该只是死板的文章列表，而应该拥有独特的视觉呼吸感、温润的排印节奏，以及让人愿意沉浸其中的光影细节。
:::

## 1. 为什么拒绝千篇一律的模版？

市面上许多开源博客框架在功能上极其完善，但往往缺失了最核心的个性：

- **过度依赖大图与重量级框架**：首次加载耗时高达数秒，缺乏纯粹阅读的轻盈感；
- **排印粗糙**：中西文字体混排缺乏微观排印规则，代码块没有一键复制与微交互；
- **深色模式体验割裂**：粗暴的反色往往导致高对比度眩光，夜间阅读极易疲劳。

:::cards[本次重构的核心指标]
| 维度 | 设计实践 | 读者体验 |
| 首屏大图 Hero | 晨光云海与悬浮日历名言卡片 | 第一眼建立深邃静谧的精神共鸣 |
| 精选特写布局 | 宽幅杂志级双栏大卡片 | 视觉焦点明确，强调重磅深度好文 |
| 4 列流体矩阵 | 响应式自适应网格与柔和微光 | 节奏张弛有度，快速浏览无负担 |
:::

## 2. 纯矢量与无框架运行时的优雅平衡

采用纯静态构建架构，在服务端或 GitHub Actions 中完成所有出版级样式的计算与排版渲染，最终交付给浏览器的只有纯净的 HTML、极简的 CSS 与零依赖的微动效脚本。
